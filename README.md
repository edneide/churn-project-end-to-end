## Estrtura do projeto
O objetivo deste projeto é construir uma solução de machine learning de ponta a ponta para previsão de churn de clientes em uma empresa de telecomunicação. 

A solução inclui:
- Exploratory Data Analysis (EDA)
- Feature engineering
- Predictive modeling
- Business insights
- A Streamlit app for churn probability prediction

## Dataset
Telco Customer Churn dataset. Disponível no Kaggle.
